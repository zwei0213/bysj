## 一、评测数据集规模与覆盖维度

评测基准文件位于 `ai-tutor-service/benchmarks/v1_eval_dataset.json`，覆盖两门物理隔离课程（`crs_dl_eval`《深度学习与大模型系统导论》与 `crs_os_eval`《现代操作系统原理》）：

| 评测维度 | 样本规模 | 覆盖场景说明 |
| :--- | :--- | :--- |
| **课程知识库文档与时间戳字幕** | **8 篇** | 含 4 讲核心讲义、2 段带秒级 `start_sec` 的已发布视频字幕、1 条教师权威回流问答（`teacher_qa`）及 1 篇跨课程干扰文档 |
| **课内标准问答对 (`in_syllabus_qa`)** | **13 条** | 覆盖概念推导、边看边问时间戳上下文、多轮对话指代消解（如“它能把可训练参数量减少多少倍？”）、三种快捷指令及教师回流命中 |
| **超纲与跨课干扰问题 (`out_of_syllabus_qa`)** | **6 条** | 覆盖量子场论、宏观经济学、基因编辑、建筑力学、区块链合约及跨课程死锁问题（同时验证严格拒答与开放拓展双模式） |
| **视频章节切分基准 (`chapterization_cases`)** | **4 组** | 含 12 段/15 段标准授课字幕、**75 段（45 分钟）长视频全时间轴采样压测**及纯文本讲稿对齐，另含静音空输入降级与单章节重生成校验 |
| **智能结构化出题用例 (`assessment_cases`)** | **6 组（共 41 题）** | 覆盖 `teacher_bank`、`chapter_practice`、`personalized_diagnostic` 三大模式、单选/多选/判断全题型及单次上限 **20 题**压测 |

## 四、V1 基线结论与 V2 演进衔接说明

1. **离线可复现与生产高可用兼备**：在无外部 API Key 环境下，64 维有符号字符/词元二元组特征哈希向量与平滑 IDF 混合检索引擎在 13 条课内问答（含多轮指代与边看边问上下文）上达到 **100.0% Recall@3**，6 条超纲与跨课干扰问题实现 **100% 精准分流**。
2. **安全合规与契约闭环**：草稿章节严格遵循教师审核发布后入库（Human-in-the-Loop），输出脱敏覆盖云端生成与本地兜底全路径，本地推理算力账单严格计 `$0.0`。
3. **V2 Harness 回归基准就绪**：后续启用 `enable_v2_harness`、`enable_v2_personalization`、`enable_v2_rsi` 新策略时，可直接复用 `benchmarks/run_v1_eval.py` 与 `/v1/ops/feedback-samples` 回流样本池进行 A/B 指标回归对比。
